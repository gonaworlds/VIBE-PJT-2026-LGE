# [PRD] Duolingo Web Core Experience Reverse-Engineering

## 1. 개요 및 비전
- **서비스 정의**: 게이미피케이션 기반 마이크로 러닝 언어 학습 웹 플랫폼
- **핵심 가치**: 짧은 학습 주기(1회 3~5분), 즉각적인 시각/청각 피드백, 스트릭(Streak) 중심의 습관 형성
- **타깃 사용자**: 매일 자투리 시간을 활용해 부담 없이 언어를 학습하고자 하는 웹 사용자

## 2. 핵심 유저 여정 (Core User Journey)
1. **학습 진입**: 학습 로드맵(Path UI)에서 현재 활성화된 레슨 노드 선택
2. **세션 진행**: 
   - 퀴즈 유형 노출 (단어 매칭, 문장 번역 조립, 선다형, 리스닝 등)
   - 상단 프로그레스 바 전진
   - 하트(생명력) 시스템 차감/유지
3. **인터랙션/피드백**:
   - 정답/오답 판정 바텀 시트 노출 + 사운드 및 캐릭터 모션 피드백
4. **세션 완료**:
   - 보상 화면 (경험치 XP, 스트릭 유지/증가, 일일 퀘스트 달성도)
   - 로드맵으로 복귀하며 노드 완료 상태 갱신

## 3. 핵심 기능 요구사항
### 3.1 학습 엔진 (Lesson Engine)
- **모듈형 문제 타입**:
  - `Word Bank`: 단어 칩을 클릭하여 문장을 조합하는 인터랙션
  - `Multiple Choice`: 이미지/텍스트 기반 선택지
  - `Pair Matching`: 탭-투-매칭 인터랙션
- **상태 관리**:
  - 세션 진행률 (`currentQuestionIndex / totalQuestions`)
  - 생명력 시스템 (`hearts`: 기본 5개, 오답 시 -1)
  - 연속 정답 카운트 및 콤보 보너스

### 3.2 게이미피케이션 시스템
- **Streak Tracker**: 연속 출석 일수 트래킹 및 보존 로직
- **XP / 리그 시스템**: 세션 완료 시 즉각적인 점수 환산
- **퀘스트(Daily Quests)**: 특정 목표(예: 3개 레슨 완주, 정답률 90% 이상) 달성 바

### 3.3 내비게이션 & 로드맵 (Path View)
- 단계별 레슨 노드 트리 (SVG/Canvas 기반 곡선 패스 연결)
- 노드 상태: `Locked`, `Active`, `Completed`, `Mastered(Gold)`

## 4. 비기능적 요구사항
- **인터랙션 반응성**: 정답 판정 및 모션 피드백 지연 시간 < 100ms
- **접근성 및 키보드 지원**: 1~9 숫자 키 선택, Space/Enter 확인 인터랙션 지원
- **사운드/모션 최적화**: Web Audio API 및 경량 Lottie/Rive 렌더링
