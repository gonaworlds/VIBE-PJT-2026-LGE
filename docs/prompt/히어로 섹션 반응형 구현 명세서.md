## 히어로 섹션 반응형 구현 명세

첨부된 데스크탑, 태블릿, 모바일 이미지를 참고하여 Duolingo 랜딩 페이지의 상단 히어로 섹션을 반응형으로 구현해줘.

### 1. 공통 구조

- 전체 배경은 흰색(`#FFFFFF`).
- 상단 헤더, 메인 히어로 섹션, 하단 언어 선택 영역으로 구성.
- 상단 헤더는 모든 화면에서 `position: fixed` 또는 `sticky`로 고정하여 스크롤 시에도 유지.
- 로고, 히어로 일러스트, 하단 국기 아이콘 등 기존 이미지 에셋은 SVG 또는 PATH 기반 벡터 형태를 유지. 임의로 래스터 이미지로 변환하지 않음.
- 기존 이미지의 색상, 비율, 형태를 유지하고 임의로 재디자인하지 않음.
- `box-sizing: border-box` 적용 및 가로 스크롤이 발생하지 않도록 처리.

### 2. 데스크탑 (1080px 이상)

- 상단 헤더: 중앙 정렬된 컨테이너 내부에 로고는 좌측, 사이트 언어 선택은 우측 배치.
- 히어로 섹션: 화면 중앙에 위치하는 좌우 2단 레이아웃.
  - 좌측: 캐릭터 일러스트.
  - 우측: 메인 카피, 시작하기 버튼, 계정이 이미 있습니다 버튼을 세로 배치.
- 일러스트와 텍스트 영역은 수평으로 정렬하고 충분한 간격 유지.
- 히어로 콘텐츠는 화면의 중앙 영역에 배치하며, 상단 헤더와 하단 언어 선택 영역을 제외한 공간을 활용.
- 하단 언어 선택 영역은 화면 하단에 고정하고 상단에 얇은 회색 구분선 적용.

### 3. 태블릿 (768px ~ 1079px)

`@media (max-width: 1079px)` 적용.

- 데스크탑의 좌우 2단 레이아웃을 세로형 레이아웃으로 변경.
- 상단 로고는 화면 중앙에 배치.
- 히어로 일러스트는 카피 위에 배치하고 중앙 정렬.
- 메인 카피는 일러스트 아래에 배치하며 텍스트 중앙 정렬.
- 시작하기 및 계정이 이미 있습니다 버튼은 카피 아래에 세로 배치.
- 일러스트, 카피, 버튼 간격을 데스크탑보다 넉넉하게 조정.
- 하단 언어 선택 영역은 화면 하단에 고정하고 가로 방향으로 국기 및 언어 목록 배치.
- 화면 너비가 줄어들어도 일러스트와 버튼의 비율을 유지하고 콘텐츠가 잘리지 않도록 처리.

### 4. 모바일 (767px 이하)

`@media (max-width: 767px)` 적용.

- 태블릿과 동일한 세로형 구조를 유지하되 모바일 전용 간격과 크기로 재조정.
- 로고는 화면 상단 중앙에 배치.
- 히어로 일러스트는 화면 중앙 상단 영역에 배치하고 적절한 여백 확보.
- 메인 카피는 일러스트 아래에 중앙 정렬하며, 좁은 화면에서 자연스럽게 줄바꿈.
- 버튼은 화면 하단에 가까운 영역에 배치하고 두 버튼 모두 가로 너비를 동일하게 설정.
- 시작하기 버튼은 초록색 배경, 계정이 이미 있습니다 버튼은 흰색 배경과 회색 테두리 유지.
- 데스크탑 및 태블릿의 하단 언어 선택 영역은 모바일에서 숨김 처리.
- 상단 로고와 하단 버튼이 화면 높이에 따라 겹치지 않도록 `min-height: 100dvh` 기반으로 구성.
- 모바일 화면에서 불필요한 가로 스크롤이 발생하지 않도록 처리.

### 5. 미디어쿼리 구현 기준

```css
/* Desktop: 1080px 이상 */
.hero {
  display: flex;
  flex-direction: row;
  align-items: center;
  justify-content: center;
}

/* Tablet: 1079px 이하 */
@media (max-width: 1079px) {
  .hero {
    flex-direction: column;
    text-align: center;
  }
}

/* Mobile: 767px 이하 */
@media (max-width: 767px) {
  .language-selector {
    display: none;
  }

  .hero {
    flex-direction: column;
  }
}
```

위 코드는 레이아웃 전환의 핵심 예시이며, 기존 HTML 구조와 CSS 클래스에 맞게 적용해줘.

### 6. 구현 시 주의사항

- 데스크탑과 태블릿/모바일은 레이아웃이 다르므로 단순한 `width` 축소만으로 구현하지 않음.
- 일러스트는 `width: 100%`, `max-width` 등을 활용하여 원본 비율 유지.
- 헤더와 하단 언어 선택 영역은 히어로 콘텐츠와 독립적으로 고정.
- 버튼의 높이, 모서리 곡률, 색상, 테두리, 폰트 굵기는 첨부 이미지와 최대한 동일하게 유지.
- `position: absolute`를 남용하지 않고 Flexbox 또는 Grid 기반으로 레이아웃 구성.
- 기존 HTML 구조와 스타일을 최대한 유지하면서 필요한 부분만 수정.
- 데스크탑, 태블릿, 모바일 각 화면에서 콘텐츠의 수직·수평 정렬과 여백이 첨부 이미지와 유사하게 보이도록 구현.
