# 문서 개요
이 문서는 사용자 프롬프트 기록용으로 ai가 읽지 않는다.

## 참조 규칙
- 파일 참조는 상대경로(`./{filename.*}`)를 사용함

## 프롬프트

이 파일을 읽고 첨부한 이미지의 화면대로 구성해서 구현해. 기본적으로 데스크탑만 우선 구현하고 기본 구성 CSS파일은README가 지정한 대로 생성해. html도 기본 구성 후 해당 상단 섹션 만들어. 이미지는 직접 생성하지 말고 박스만 구성해.
