### 기술 계획

1. 사용자가 요청한 Lottie만 외부 의존성으로 추가합니다. Vanilla/ES Modules 구조와 번들러 없는 실행을 유지합니다. 버전을 고정한 lottie-web 파일과 라이선스를 로컬 vendor 경로에 보관하는 안입니다.
2. SVG 렌더러를 기본으로 사용합니다. JSON 파일을 img의 src로 넣지 않고, 기존 이미지 자리의 컨테이너에 플레이어를 생성합니다. SVG는 로딩 중·실패·모션 감소 시의 정적 대체 이미지로 보존합니다.
3. 공통 lottie-scene 모듈과 장면별 설정을 분리합니다. 기존 클래스가 담당하는 크기/비율을 유지하고 데이터 속성으로 JS를 연결합니다. 새 스타일은 토큰을 사용합니다.
4. 히어로부터 우선 로드하고 하단은 화면 접근 시 JSON을 지연 로드합니다. IntersectionObserver로 가시성을 감지하고 화면 밖 또는 비활성 탭에서는 일시정지합니다. 재진입은 진행 지점에서 이어가며 기본은 장면당 1회 재생입니다. 반복 재생은 별도 선택 사항입니다.
5. prefers-reduced-motion에서는 SVG를 유지하고 재생하지 않습니다. 장식 애니메이션은 보조기기에서 숨기고 기존 이미지의 의미 있는 대체 설명은 컨테이너에 보존합니다.
6. fetch/JSON 파싱/플레이어 오류 시 SVG를 유지하며 정리 함수에서 플레이어·관찰자·이벤트를 해제합니다. HTTP 로컬 서버에서 검증합니다.

### 주의점과 구현 단계에서의 확인

- benefit_02 JSON에는 표현식 1개, 다운로드 전경 JSON에는 표현식 5개가 있습니다. 표현식 없는 light 빌드는 바로 채택하지 않습니다. 정식 표현식 지원 빌드를 후보로 두고 실제 경로 변형을 비교합니다. 표현식 엔진의 동적 코드 실행과 기존 규약/CSP의 충돌 여부도 도입 전에 확인합니다. 충돌 시 표현식 베이킹 등 대안을 정하고 보고합니다.
- BACKGROUND JSON의 시작 프레임은 250입니다. 0부터 시작한다고 가정하지 않습니다.
- benefit_02는 Intro 0~190, Loop 190~532 부근 마커가 있습니다. 마커가 op를 약간 넘는 경우 실제 유효 프레임으로 제한합니다.
- StayMotivated의 0/20 마커 및 ending assets의 범위 밖 마커는 자동으로 루프 범위로 사용하지 않습니다. 미리보기로 확인합니다.
- 다운로드 두 장면의 길이는 서로 달라 임의로 전체 길이를 맞추거나 같은 프레임으로 강제 동기화하지 않습니다. 배경과 전경의 구도·재생 목적을 확인한 뒤 결정합니다.
- 기존 getstarted.svg에는 녹색 배경/곡선이 포함됩니다. 이미지 전체를 제거하기 전에 Ending JSON의 실제 배경 구성과 중복 여부를 확인합니다.
- 총 30MB이므로 일괄 선로드하지 않습니다. 압축 전송과 화면 밖 일시정지, 필요 시 경량화 검토가 필요합니다.

## 2. 승인된 Lottie 애니메이션 구현

### 적용

- 사용자 계획 승인 후 header 히어로부터 benefit 1~4, downloads 배경/전경, Super Duo, English Test, Ending 순서로 적용했습니다. 10개 이미지 위치에 JSON 11개를 연결했습니다.
- lottie-web 5.13.0 정식 플레이어와 MIT 라이선스를 assets/js/vendor에 저장했습니다. 표현식이 있는 JSON을 위해 full 빌드를 사용합니다. 애플리케이션 코드에는 eval/new Function을 추가하지 않았습니다. 라이브러리 표현식 엔진 때문에 향후 엄격한 CSP 배포 시 베이킹 또는 호환성 검토가 필요합니다.
- lottie-scenes.js에서 플레이어 및 JSON 지연 로드, 화면 진입 시 1회 재생, 이탈/비활성 탭 일시정지, 재진입 이어 재생, 완료 후 정지, 모션 감소 시 SVG 표시를 관리합니다.
- 이미지에 data-lottie-image 훅을 추가했습니다. 런타임에 기존 클래스와 크기를 가진 컨테이너를 만들고 원본 SVG를 로딩/실패 대체 이미지로 유지합니다. JS가 없으면 원래 SVG가 그대로 표시됩니다.
- 다운로드는 동일 좌표계의 배경/전경을 두 레이어로 렌더링합니다. Ending 역시 기본 배경과 Duo를 합성하며, 장면별 자연 재생 시간을 유지합니다.
- 다운로드의 기존 img 전용 CSS를 직접 자식 이미지/애니메이션 컨테이너 공통으로 수정해 높이와 absolute 배치를 유지했습니다.
- 로고, 국기, 스토어 아이콘, Super 로고는 정적으로 유지했습니다. 원본 JSON/SVG는 수정하지 않았습니다.

### 검증

- main.js와 lottie-scenes.js의 Node 문법 검사 통과.
- 로컬 HTTP 서버 + 헤드리스 Chrome에서 모든 10개 장면 ready, JSON 11개 렌더링 및 JS 예외 없음 확인.
- 375/768/1024/1280px에서 가로 넘침 없음과 모든 장면의 유효한 크기 확인. 다운로드 높이 0 문제를 발견해 수정 후 재검증했습니다.
- 데스크톱 히어로, Super Duo, 다운로드, Ending 합성과 모바일 다운로드/Ending 화면을 시각 확인했습니다.
- 최초 진입 시 히어로만 로드되고 하단 장면은 미로드임을 확인했습니다.
- 화면 밖 플레이어 일시정지, 모션 감소 시 모든 플레이어 정지 및 SVG 표시를 확인했습니다.
- 히어로를 가속 재생하여 자연 완료(289/290 프레임) 후 정지 및 재진입 시 미재생을 확인했습니다.
- JSON 요청을 차단해 failed 상태에서 SVG가 보이는 것을 확인했습니다.
- 전체 lint/Lighthouse 및 타 브라우저 성능 검사는 미실시. 대용량 JSON은 지연 로드로 대응하며 원본 용량은 유지합니다.
