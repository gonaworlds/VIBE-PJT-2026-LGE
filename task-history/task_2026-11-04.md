# 작업 기록 — 2026-11-04

## 1. 스크롤 반응형 고정 헤더 내비게이션

### 요청

스크롤 중 상단 내비게이션을 고정 표시하고, 히어로의 로그인 버튼을 지나면 첨부 화면처럼 로고와 시작하기 CTA가 있는 간결한 내비게이션으로 전환합니다. `.benefit` 영역을 벗어나면 위로 사라지는 애니메이션을 적용하고, 모바일에서는 로고를 잘라 아이콘처럼 표시합니다.

### 변경 및 결과

- `index.html`에 스크롤 전환용 고정 내비게이션을 추가했습니다. Duolingo 로고와 가입 시작 CTA를 포함합니다.
- `assets/js/main.js`에서 로그인 버튼 하단이 뷰포트 상단을 지난 뒤부터 `.benefit` 섹션 끝까지 메뉴를 표시하도록 했습니다. 스크롤/리사이즈를 감지하고 요청 프레임 단위로 상태를 갱신합니다.
- 표시 중이 아닐 때 메뉴는 `aria-hidden`, `inert`, 링크의 `tabindex`로 포커스 및 보조기기 탐색에서 제외합니다.
- `assets/css/layout/site-header.css`에 위쪽 슬라이드 진입·퇴장 전환과 모션 감소 설정을 추가했습니다.
- 모바일에서는 로고 이미지 박스를 정사각형으로 제한하고 `object-fit: cover` 및 왼쪽 정렬로 부엉이 심볼만 보이도록 했습니다.

### 검증

- `node --check assets/js/main.js`를 통과했습니다.
- 데스크톱에서 초기 숨김, 로그인 CTA 통과 후 상단 고정 표시, `.benefit` 영역 종료 후 위로 이동하며 숨김을 확인했습니다.
- 모바일에서 심볼 크롭(`object-fit: cover`), 시작하기 버튼 위치, 가로 오버플로가 없는 것을 확인했습니다.
- 숨김 상태 링크는 `tabindex="-1"`/`inert`, 표시 상태 링크는 키보드 탐색 가능 상태가 되는 것을 확인했습니다.

## 2. 기본 헤더 고정 및 전환 기준 수정

### 요청

`.benefit` 영역으로 스크롤하는 동안에도 로고가 포함된 기본 헤더 바를 상단에 고정하고, 히어로의 “계정이 이미 있습니다” 버튼을 지난 뒤에는 “시작하기” CTA가 포함된 간편 고정 메뉴로 전환합니다.

### 변경 및 결과

- 기본 `.inner-box`를 상단 고정 상태로 유지하고, 로그인 버튼의 하단이 뷰포트 상단을 지난 시점에 간편 메뉴로 전환되도록 했습니다.
- 간편 메뉴는 `.benefit` 영역이 끝날 때까지 표시하고, 영역을 벗어나면 위로 사라집니다.
- 기존 스크롤 위치 복원 상태에서 초기 화면을 확인하면 상태가 혼동될 수 있어, 최상단으로 즉시 이동한 새 페이지에서 다시 검증했습니다.

### 검증

- 데스크톱에서 최상단은 기본 로고 헤더, 로그인 버튼 통과 후부터 `.benefit` 종료 전까지는 간편 메뉴, 종료 후에는 두 메뉴 모두 숨겨지는 동작을 확인했습니다.
- 모바일에서도 로그인 버튼 통과 후와 `.benefit` 영역에서 간편 메뉴가 고정 표시되는 것을 확인했습니다.
- 모바일 로고의 `object-fit: cover` 및 가로 오버플로가 없는 상태를 확인했습니다.

## 3. 헤더 메뉴 높이 및 즉시 전환 조정

### 요청

기본 `.inner-box`와 `.site-header__compact`의 높이를 간편 메뉴 높이로 통일하고, 두 메뉴 사이를 바꿀 때는 애니메이션 없이 즉시 전환합니다. `.benefit` 영역을 벗어날 때 간편 메뉴가 위로 사라지는 애니메이션은 유지합니다.

### 변경 및 결과

- 두 메뉴의 높이를 공통 `--compact-nav-height` 값으로 통일했습니다.
- 기본 메뉴와 간편 메뉴의 일반 상태 전환에서는 CSS transition을 비활성화했습니다.
- `.benefit` 끝을 지난 상태에만 간편 메뉴의 퇴장 transition을 적용해 위로 사라지는 동작을 유지했습니다. 모션 감소 설정도 해당 퇴장 애니메이션에 반영됩니다.

### 검증

- 데스크톱과 모바일에서 두 메뉴의 높이가 모두 72px로 같고, 로그인 버튼 통과 시 애니메이션 없이 바뀌는 것을 확인했습니다.
- `.benefit` 종료 직후에는 간편 메뉴의 위쪽 퇴장 애니메이션이 실행되는 것을 확인했습니다.
- 모바일 가로 오버플로가 없고 `node --check assets\\js\\main.js`를 통과했습니다.

## 4. English Test 섹션 구현 및 내비게이션 재등장

### 요청

제공된 데스크톱·태블릿·모바일 화면에 맞춰 `.englishtest`를 구현하고, 해당 영역에 진입하면 숨겨져 있던 간편 헤더 메뉴가 아래로 내려오며 표시되도록 합니다.

### 변경 및 결과

- `.englishtest`에 타이틀, 설명, 영어 능력 인증 링크, `englishtest.svg` 일러스트를 추가했습니다.
- 데스크톱은 텍스트와 일러스트를 가로 배치하고, 태블릿·모바일은 가운데 정렬 세로 배치로 구성했습니다.
- 스크롤 상태 계산에 `.englishtest` 구간을 포함해 해당 영역 진입 시 간편 메뉴가 다시 나타나도록 연결했습니다. 일반 메뉴 전환은 즉시 처리하고, benefit 이후 및 English Test 영역 진입·이탈에는 아래/위 슬라이드 전환을 적용합니다.

### 검증

- 브라우저에서 데스크톱(1532×768), 태블릿(926×768), 모바일(768×1024) 레이아웃을 확인했습니다. 데스크톱은 가로, 나머지는 세로 배치이며 SVG가 정상 로드되고 가로 넘침이 없습니다.
- benefit 끝에서 메뉴가 위로 숨고, `.englishtest` 진입 시 메뉴가 다시 아래로 나타나는 것을 확인했습니다.
- `.englishtest` 시작 경계에서 소수 픽셀 차이로 메뉴 표시가 누락되지 않도록 1px 허용값을 적용했습니다.
- `node --check assets\\js\\main.js`를 통과했습니다.

## 18. container 스크롤 배경색 전환

- .container에 data-js-scroll-background 훅을 추가하고 배경색을 흰색에서 #DFF5FF로 스크롤 진행에 따라 전환했습니다.
- 적용 기준: container 상단이 뷰포트 하단에 닿으면 진행률 0, 뷰포트 상단에 닿으면 1입니다. 이후 목표색을 유지하고 역방향 스크롤 시 흰색으로 돌아옵니다.
- tokens.css에 --color-container-scroll-bg를 정의했습니다. landing.css의 가상 요소 배경 레이어에 opacity를 적용해 콘텐츠 투명도에는 영향을 주지 않습니다.
- scroll-background.js는 passive scroll, requestAnimationFrame, ResizeObserver와 load/pageshow/resize로 상태를 갱신합니다. destroy 함수로 리스너·관찰자·예약 프레임을 해제합니다.
- 모션 감소 설정에서는 배경색을 목표색으로 고정합니다.
- 검증: JS 문법 검사 통과. Chrome 375px/1280px에서 진행률 0→0.5→1→0.5→0에 opacity가 동일하게 대응함을 확인했습니다. 목표색 rgb(223,245,255), 가로 넘침 없음, JS 예외 없음, 모션 감소 opacity 1 확인.
- 변경 파일: index.html, tokens.css, landing.css, main.js, 신규 scroll-background.js 및 작업 기록.

## 19. container 배경 전환 구간 수정

- 진입 중에는 흰색을 유지하고, container 상단이 화면 상단에 닿은 뒤 내부 스크롤 진행에 따라 #DFF5FF로 변하도록 수정했습니다.
- 전환 거리는 container 높이 - 화면 높이이며 최소 화면 높이로 설정합니다. 현재 긴 container에서는 하단이 화면 하단에 닿으면 목표색에 도달합니다. 역방향 전환 및 모션 감소 설정은 유지합니다.
- 변경 파일: assets/js/scroll-background.js 및 작업 기록.
- JS 문법 검사 통과. Chrome 375/1280px에서 진입·시작 opacity 0, 중간 약 0.5, 끝 1, 역방향 0 복귀를 확인했습니다. 가로 넘침과 페이지 JS 예외가 없습니다.
