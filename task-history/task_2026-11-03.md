# 작업 기록 — 2026-11-03

## 1. 랜딩 페이지 기본 화면 구현

### 요청

첨부된 Duolingo 한국어 데스크톱 랜딩 화면을 참고해 상단 섹션을 구현합니다. README와 `spec-kit/AGENTS.md`의 프로젝트 구조 및 CSS 규약을 따르고, 이미지는 생성하거나 복제하지 않고 자리만 만듭니다.

### 변경 및 결과

- `index.html`에 시맨틱 헤더, 히어로 섹션, 가입/로그인 CTA, 하단 언어 목록을 구성했습니다.
- 로고와 메인 일러스트는 이미지를 사용하지 않고 텍스트 자리표시와 박스로 표현했습니다.
- `assets/css/main.css`를 CSS 진입점으로 만들고 reset, 토큰, 타이포그래피, 기본 스타일, 레이아웃, 컴포넌트, 페이지, 접근성 스타일을 분리했습니다.
- `.inner-box` 및 `.part` 구조와 Flexbox 레이아웃, 디자인 토큰, 버튼 립/눌림 스타일을 사용했습니다.
- `assets/js/main.js`에 하단 학습 언어 가로 스크롤과 좌우 버튼 동작을 구현했습니다.
- 가입/로그인 CTA는 각각 `https://www.duolingo.com/register`, `https://www.duolingo.com/log-in`으로 연결됩니다.

### 검증

- 브라우저에서 320, 375, 768, 1024, 1280, 1355px 너비를 확인했습니다. 가로 오버플로가 없었고 768px 이상은 좌우 히어로, 좁은 화면은 세로 배치로 표시됐습니다.
- 학습 언어 스크롤 버튼, 사이트 언어 `details` 메뉴, 화면 제목과 랜드마크를 브라우저에서 확인했습니다.
- 브라우저 페이지 오류는 없었습니다. 이미지 요소는 0개였습니다.
- Node.js가 실행 환경에 없어 `node --check`는 실행하지 못했습니다.

## 2. 스타일 자산 경로 통합

### 요청

루트 `css/`와 `assets/css/`로 나뉜 CSS 자산 관리를 `assets/` 아래로 통합합니다.

### 사전 확인

- `assets/css/`에 실제 페이지에서 사용하는 CSS 파일과 진입점이 있었습니다.
- 루트 `css/style.css`는 비어 있었고, HTML/CSS/JS 코드에서 참조되지 않았습니다.
- 루트 `css/font/`에는 TTF 파일 두 개가 있었습니다.

### 변경 및 결과

- `css/font/Feather Bold-normal-700-100.ttf`를 `assets/fonts/Feather Bold-normal-700-100.ttf`로 이동했습니다.
- `css/font/Duolingo Sans Thin-normal-700-100.ttf`를 `assets/fonts/Duolingo Sans Thin-normal-700-100.ttf`로 이동했습니다.
- 참조되지 않던 빈 `css/style.css`를 제거하고 비어 있는 `css/font/`, `css/` 폴더를 정리했습니다.
- 페이지 스타일 경로는 `./assets/css/main.css`로 유지했습니다. 기존 `assets/css/` 하위 스타일 구조와 참조는 변경하지 않았습니다.

### 검증

- `assets/css/main.css`, `assets/css/base/tokens.css` 및 이동한 폰트 두 파일이 존재하는지 확인했습니다.
- 루트 `css/` 폴더가 제거됐는지 확인했습니다.
- 코드에서 페이지 스타일시트를 참조하는 경로가 `assets/css/main.css`인지 확인했습니다.

## 후속 작업 시 유의사항

- 작업 전에 `summary.md`와 이 파일을 확인해 위 항목을 중복 구현하거나 폰트를 다시 옮기지 않습니다.
- 현재 CSS 진입점은 `assets/css/main.css`, 토큰 파일은 `assets/css/base/tokens.css`, JavaScript 진입점은 `assets/js/main.js`입니다.
- `assets/fonts/`의 Duolingo 전용 폰트는 현재 로드되지 않습니다. 프로젝트 규약상 전용 폰트 사용이 승인된 것으로 간주하지 말고, 폰트 정책 변경 전 라이선스와 규약을 확인합니다.
- 이후 작업도 기존 HTML의 헤더/히어로/푸터와 반응형 동작을 유지하고, 변경이 있으면 이력 요약 및 날짜별 상세 기록을 함께 갱신합니다.
