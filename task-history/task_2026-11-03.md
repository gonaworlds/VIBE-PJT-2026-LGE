## 1. 랜딩 페이지 기본 화면 구현

### 요청

첨부된 Duolingo 한국어 데스크톱 랜딩 화면을 참고해 상단 섹션을 구현합니다. README와 `spec-kit/AGENTS.md`의 프로젝트 구조 및 CSS 규약을 따르고, 이미지는 생성하거나 복제하지 않고 자리만 만듭니다.

### 변경 및 결과

- `index.html`에 시맨틱 헤더, 히어로 섹션, 가입/로그인 CTA, 하단 언어 목록을 구성했습니다.
- 로고와 메인 일러스트는 이미지를 사용하지 않고 텍스트 자리표시와 박스로 표현했습니다.
- `assets/css/main.css`를 CSS 진입점으로 만들고 reset, 토큰, 타이포그래피, 기본 스타일, 레이아웃, 컴포넌트, 페이지, 접근성 스타일을 분리했습니다.
- `.inner-box` 및 `.part` 구조와 Flexbox 레이아웃, 디자인 토큰, 버튼 립/눌림 스타일을 사용했습니다.
- `assets/js/main.js`에 하단 학습 언어 가로 스크롤과 좌우 버튼 동작을 구현했습니다.
- 가입/로그인 CTA는 각각 `https://www.duolingo.com/register`, `https://www.duolingo.com/log-in`으로 연결됩니다.

### 검증

- 브라우저에서 320, 375, 768, 1024, 1280, 1355px 너비를 확인했습니다. 가로 오버플로가 없었고 768px 이상은 좌우 히어로, 좁은 화면은 세로 배치로 표시됐습니다.
- 학습 언어 스크롤 버튼, 사이트 언어 `details` 메뉴, 화면 제목과 랜드마크를 브라우저에서 확인했습니다.
- 브라우저 페이지 오류는 없었습니다. 이미지 요소는 0개였습니다.
- Node.js가 실행 환경에 없어 `node --check`는 실행하지 못했습니다.

### 사전 확인

- 참조되지 않던 빈 `css/style.css`를 제거하고 비어 있는 `css/font/`, `css/` 폴더를 정리했습니다.

### 검증

## 3. 히어로 반응형 명세 구현

### 명세

`C:\Github_LGE\VIBECODING-2026-DUOLINGO\히어로 섹션 반응형 구현 명세서.md` 및 첨부된 데스크톱·태블릿·모바일 화면을 기준으로 기존 히어로 레이아웃을 반응형으로 조정했습니다.

### 변경 및 결과

- 헤더를 상단 고정으로 변경하고, 모바일·태블릿에서는 로고 자리표시를 가운데 정렬하고 사이트 언어 선택을 숨겼습니다. 데스크톱에서는 로고와 언어 선택을 좌우로 배치합니다.
- 1080px 이상은 히어로를 좌우 배치합니다.
- 768–1079px은 일러스트 자리표시, 카피, CTA 순으로 중앙 정렬하는 세로형으로 변경했습니다.
- 767px 이하에서는 동일한 세로 흐름을 사용하고 모바일 전용 간격과 글자 크기를 적용했습니다. CTA 두 개는 같은 너비로 화면 하단 가까이에 두고, 하단 언어 선택 영역은 숨깁니다.
- 데스크톱과 태블릿의 언어 선택 바를 하단 고정하고, 상단 구분선을 유지했습니다.
- 새 반응형 크기와 간격은 `assets/css/base/tokens.css`에 토큰으로 추가했습니다.
- 프로젝트의 `spec-kit/AGENTS.md` PART C 13항은 Duolingo 로고, Duo 마스코트, 캐릭터 및 공식 이미지를 복제·임베드하지 않도록 규정합니다. 따라서 요청된 이미지 자산 대신 기존 텍스트/일러스트 자리표시를 유지했습니다. 실제 브랜드 이미지를 반영하려면 사용 권한이 확인되고 프로젝트 규약과 일치하는 자산이 필요합니다.

### 검증

- 브라우저에서 320×568, 375×812, 767×1536, 768×768, 1079×768, 1080×768, 1355×768, 1920×1080을 확인했습니다.
- 모든 확인 크기에서 문서 가로 오버플로가 없었습니다.
- 1080px 경계에서 가로/세로 히어로 전환, 767px 경계에서 하단 언어 바 숨김, 768px 이상 하단 고정 바 노출, 모든 크기의 고정 헤더를 확인했습니다.
- 767×1536에서 CTA가 화면 하단 12px 안쪽에 위치하고, 일러스트와 카피가 겹치지 않는 것을 확인했습니다.
- 320×568에서도 CTA가 화면 하단 12px 안에 들어오도록 짧은 화면용 간격을 조정하고, 문서 세로 길이가 뷰포트에 맞는 것을 확인했습니다.
- 768px 화면에서 하단 언어 스크롤의 다음/이전 버튼을 작동시켜 실제 좌우 이동을 확인했습니다. 첫 키보드 탭에서 스킵 링크 포커스도 확인했습니다.
