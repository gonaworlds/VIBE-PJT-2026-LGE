# starter_set.py 사용법

이 파일은 폴더와 파일을 미리 설정한 이름으로 일괄 생성하는 python 파일이다.

## 사용법

1. 루트 폴더 경로에서 터미널을 실행한다.
2. `python starter_set.py`를 입력한다.

## 이름 설정하는 법

### 폴더명 추가 및 변경

```python

base_dir = Path(__file__).resolve().parent
folder_names = ["css", "js", "images", "data", "spec-kit"]  # 만들 폴더 이름으로 바꾸세요

```
`["폴더명1","폴더명2","폴더명3", " ", ...]`

- 폴더명을 추가하거나 변경하고 싶다면 `""(큰 따옴표)`안에 이름을 작성하여 추가한다.

### 파일명 추가 및 변경

> 
```python

file_paths = ["README.md","index.html", "css/style.css", "js/main.js"]  # 만들 파일 경로로 바꾸세요

```

`["파일명1.확장자", "파일명2.확장자", "파일명3.확장자", " ", ...]`

 `{파일명}.{확장자}` 형식으로 파일이름을 추가하거나 변경할 수 있다. 

- 폴더 안에 파일을 만드려면 `"폴더명/파일명.확장자"`형식으로 작성한다.
